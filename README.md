# Практическая работа №3. Создание пайплайна предобработки данных

## 1. Цель проекта

Цель практической работы заключается в создании пайплайна предобработки данных с использованием библиотеки Scikit-learn.

Основная задача — подготовить данные для дальнейшего машинного обучения, обработать пропущенные значения, преобразовать категориальные признаки и масштабировать числовые признаки.

Также необходимо предотвратить **утечку данных (Data Leakage)** между обучающей и тестовой выборками.

## 2. Используемые технологии

В проекте используются следующие инструменты:

- **Python** — язык программирования.
- **Pandas** — загрузка, обработка и анализ данных.
- **Scikit-learn** — создание пайплайнов и предобработка данных.
- **VS Code** — среда разработки.
- **Git и GitHub** — контроль версий и хранение проекта.

## 3. Описание набора данных

Для выполнения практической работы используется набор данных о пассажирах «Титаника» — `Titanic-Dataset.csv`.

Данные содержат информацию о пассажирах, включая возраст, пол, стоимость билета и класс обслуживания.

В проекте используются следующие признаки:

| Признак | Описание |
|---|---|
| `Age` | Возраст пассажира |
| `Fare` | Стоимость билета |
| `SibSp` | Количество братьев, сестёр или супругов на борту |
| `Parch` | Количество родителей или детей на борту |
| `Pclass` | Класс обслуживания |
| `Sex` | Пол пассажира |
| `Embarked` | Порт посадки |
| `Survived` | Выжил ли пассажир: 0 — нет, 1 — да |

Признак `Survived` используется как целевая переменная. Остальные выбранные признаки используются для подготовки входных данных.

## 5. Загрузка и анализ данных

Для загрузки данных используется библиотека Pandas.

Программа читает файл `Titanic-Dataset.csv`, определяет размер набора данных и выводит количество пропущенных значений в каждом столбце.

Это позволяет понять структуру данных и определить, какие признаки требуют предобработки.

## 6. Разделение данных

Перед предобработкой данные разделяются на две части:

- **Обучающая выборка (80%)** — используется для настройки параметров предобработки.
- **Тестовая выборка (20%)** — используется для проверки преобразований на данных, которые не участвовали в обучении пайплайна.

Для разделения применяется функция `train_test_split()`.

Параметр `random_state=42` обеспечивает воспроизводимость результатов. Параметр `stratify=y` помогает сохранить примерно одинаковое соотношение выживших и погибших пассажиров в обеих выборках.

**Важно:** разделение выполняется до обучения компонентов предобработки. Это помогает избежать утечки данных.

## 7. Обработка пропущенных значений

В наборе данных могут встречаться пропущенные значения. Для их обработки применяются разные стратегии в зависимости от типа признака.

### 7.1. Числовые признаки

Для признаков `Age`, `Fare`, `SibSp` и `Parch` используется заполнение пропусков медианой.

Медиана — это среднее по положению значение в отсортированном наборе данных. В отличие от обычного среднего арифметического, она менее чувствительна к очень большим или маленьким значениям.

Используется `SimpleImputer(strategy="median")`.

### 7.2. Признак `Pclass`

Пропущенные значения класса обслуживания заполняются наиболее часто встречающимся значением.

Используется `SimpleImputer(strategy="most_frequent")`.

### 7.3. Признаки `Sex` и `Embarked`

Для этих категориальных признаков пропущенные значения заменяются текстом `Unknown`, то есть «Неизвестно».

Используется `SimpleImputer(strategy="constant", fill_value="Unknown")`.

## 8. Масштабирование числовых признаков

Числовые признаки могут иметь разные диапазоны значений. Например, возраст измеряется десятками, а стоимость билета может составлять сотни условных единиц.

Для приведения признаков к сопоставимому масштабу используется `StandardScaler`.

Он преобразует значения так, чтобы на обучающей выборке каждый числовой признак имел среднее значение около 0 и стандартное отклонение около 1.

Масштабирование помогает алгоритмам машинного обучения, чувствительным к масштабу признаков.

## 9. Кодирование категориальных признаков

Многие алгоритмы машинного обучения не могут напрямую работать с текстовыми категориями. Поэтому категориальные признаки преобразуются в числовой формат.

Для признаков `Pclass`, `Sex` и `Embarked` используется `OneHotEncoder`.

Метод создаёт отдельные бинарные столбцы для категорий. Например, признак `Sex` может преобразоваться в отдельные столбцы для категорий `female` и `male`.

Параметр `handle_unknown="ignore"` позволяет обрабатывать категории, которые не встречались при обучении кодировщика.

## 10. Создание пайплайнов

Пайплайн (`Pipeline`) объединяет несколько последовательных этапов обработки данных в один объект.

В проекте создаются три пайплайна:

1. **Числовой пайплайн:** заполнение пропусков медианой и масштабирование числовых признаков.
2. **Пайплайн `Pclass`:** заполнение пропусков наиболее частым значением и кодирование категорий.
3. **Категориальный пайплайн:** замена пропусков на `Unknown` и кодирование признаков `Sex` и `Embarked`.

Такой подход делает код более структурированным и упрощает повторное применение преобразований.

## 11. Использование ColumnTransformer

`ColumnTransformer` позволяет применять разные способы обработки к разным группам столбцов.

В данном проекте он объединяет три пайплайна:

- обработку числовых признаков;
- обработку класса обслуживания;
- обработку остальных категориальных признаков.

В результате получается единый объект `preprocessor`, который отвечает за всю предобработку данных.

## 12. Предотвращение утечки данных

Утечка данных возникает, когда информация из тестовой выборки влияет на обучение или настройку модели и этапов предобработки.

Чтобы избежать этой проблемы, в проекте используются два разных метода:

- `fit_transform()` — обучает компоненты предобработки на обучающей выборке и преобразует её;
- `transform()` — преобразует тестовую выборку, используя уже найденные параметры.

Например, медиана для заполнения пропусков и параметры масштабирования вычисляются только по обучающим данным.

Тестовая выборка не используется для определения этих параметров.

Это один из главных принципов корректной подготовки данных для машинного обучения.

## 13. Проверка результатов

После выполнения предобработки программа проверяет:

- количество строк в обучающей и тестовой выборках;
- размеры исходных и обработанных данных;
- одинаковое количество признаков в обеих выборках;
- отсутствие пропущенных значений в обработанных признаках.

Эти проверки помогают убедиться, что пайплайн работает корректно.

## 14. Сохранение обработанных данных

После предобработки результаты сохраняются в формате CSV в папке `results/`.

Создаются два файла:

- `train_processed.csv` — обработанная обучающая выборка;
- `test_processed.csv` — обработанная тестовая выборка.

В оба файла добавляется целевая переменная `Survived`, чтобы сохранить связь между признаками и ответами.

Полученные файлы можно использовать в дальнейших практических работах по машинному обучению.
